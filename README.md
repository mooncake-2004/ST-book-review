# 千页书评 · ST Book Review

为 SillyTavern 小说聊天提供独立的“读后空间”，视觉风格参考 `st-theater` 的暖色纸张、卡片和主题变量体系。

## 功能

- 每一条 AI 回复都有独立书评区；下拉框可回看历史楼层。
- 支持 LZ、其他读者、楼中楼以及用户回复；“更新评论”会结合已有讨论继续生成。
- 角色私聊：角色知道自己是小说角色，可在正文之外谈心。
- 普通聊天：参考 Story Oracle 的普通模式，以只读正文上下文进行戏外讨论。
- 所有侧聊均与正文隔离，不写进主聊天。
- 悬浮气泡可在设置中关闭；关闭后从 SillyTavern 魔法棒菜单的“千页书评”打开。
- 数据优先绑定当前聊天元数据保存；旧版环境自动回退到浏览器本地存储。

## 安装

在 SillyTavern 的第三方扩展安装器中输入：

```
https://github.com/mooncake-2004/ST-book-review
```

需要较新的 SillyTavern 版本，以使用扩展上下文中的 `generateRaw` 生成接口。
